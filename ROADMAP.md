# Roadmap

## Phase 0 — Architecture
- Select game engine/framework
- Define simulation boundaries
- Define data schemas
- Define testing strategy
- Create minimal project skeleton

## Phase 1 — Workshop prototype
- One vehicle
- Part inventory
- Engine removal
- Disassembly
- Part inspection
- Assembly validation
- Basic save/load

## Phase 2 — Engine simulation
- Combustion approximation
- Torque curve
- RPM
- fueling
- ignition
- boost
- thermal model
- lubrication model
- failure conditions

## Phase 3 — ECU + dyno
- tuneable maps
- dyno visualization
- telemetry
- repeatable testing

## Phase 4 — Driving
- basic vehicle physics
- gearbox
- differential
- tires
- brakes
- basic suspension
- test track

## Phase 5 — Progression
- buying/selling
- repair costs
- jobs
- parts market
- reputation
- money loop

## Phase 6 — Expansion
- more engines
- more vehicles
- deeper suspension
- advanced drivetrain
- damage/wear
- modding tools
- content pipeline

## Rule
Each phase should produce a demonstrable playable/testable increment before proceeding.
